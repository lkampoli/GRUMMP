From version 0.6.6 to 0.7:

  • Factored insert-and-swap out of the mesh classes. All calls to insert-and-swap functions in those classes are now obsolete and have been removed.
  • Can now specify a curve (2D) or surface (3D) to insert into an existing mesh. The mesh is changed only near the curve / surface, and mesh quality (including length scale) is maintained.
  • Multithreaded parallel implementations of swapping and isotropic refinement.
  • Better mesh alignment for 2D anisotropic adaptation.
