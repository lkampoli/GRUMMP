From version 0.7 to 0.7.1:

  • Preliminary version of a new advancing layer meshing scheme designed to fill the whole domain (for either closed or open domains).
  • New 2D point insertion options, including one that mimics advancing layer mesh generation.
  • Lots of internal code cleanup, especially for lengthscale and quality calculations; these changes are mostly not visible to users.
