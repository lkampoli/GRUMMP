From version 0.7.1 to 0.7.2:

  • Significant improvements to the entire-domain advancing layer meshing scheme. It's still very much at the alpha stage, but it's getting there. (If you'd like to support moving this work along, contact Carl Ollivier-Gooch at cfog@mech.ubc.ca.)
    • 2D: reasonably robust, including some ability to specify initial marching distance
    • 3D: definitely alpha. Complex corners are a serious problem. Also, requires some external software for many cases. These dependencies will be removed in later versions.
    • Surface: under development.
  • Now compatible with gcc 7.
  • Lots more internal code cleanup.
  • Fixed (again, but this time more cleanly and permanently) problems with isotropic mesh adaptation.
